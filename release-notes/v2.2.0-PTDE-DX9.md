# Dark Souls: Prepare to Die Edition, FPS Unlock v2.2.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 2.2.0

Higher frame rates in busy places. There the game's draw thread, not the GPU, sets the frame rate, and most of its time went to its own overhead. The picture and the game are unchanged; every part has its own switch.

- **Less work on the draw thread.** No per-frame wait for the GPU on the eye-adaptation copy (`AsyncReadback`), repeated sampler state calls skipped (`FilterSamplerStates`), the effects library's leftover debug checks off (`FastEffects`), 28 math helpers replaced with bit-for-bit identical SSE versions (`FastRenderMath`), the game's read locks without kernel calls (`FastReadLocks`), and surfaces the game made and threw away every frame reused (`ReuseSurfaces`).
- **No more slowdown while standing still** with fewer than four controllers: empty controller slots are checked once a second instead of every frame.
- **No more hitch every 5 seconds** (`SteamPauseGuard`). On Windows the Steam client pauses about every 5 s to check Wi-Fi, and every Steam call made meanwhile waits; the game makes one every frame. The game's calls now go only right after Steam has answered quickly, the lobby filter it sets every frame waits for the next lobby search, and its online packets are sent from a thread of their own.
- On a Ryzen 7 5800X3D and an RTX 3090 at 4K: Darkroot Garden's busiest spot 79 to 157-171 FPS, Blighttown 58-73 to 96 (129 with DXVK), the Undead Burg bridge 45-125 to 155-168.
- **DXVK: G-SYNC / FreeSync works** while Windows HDR is off (`DxvkExclusiveFullscreen = auto`). It needs exclusive fullscreen, and with HDR on Windows would switch HDR off for as long as the game holds it, so then DXVK keeps HDR and runs without variable refresh (Direct3D 9 has both). `true` takes exclusive fullscreen anyway.
- **DXVK colors with Windows HDR:** NVIDIA's RTX HDR, if it is on for the game in the NVIDIA app, applies only under DXVK and crushes the shadows. Turn it off for the game for the same picture as Direct3D 9; the log says when it is active.

All new switches are on by default, also when your INI does not list them yet.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Upgrading: replace `xinput1_3.dll`; your INI keeps working. Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate. In-engine cutscene cameras are blended; a hard cut still snaps, and pre-rendered movies stay 30 FPS. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
