# Dark Souls: Prepare to Die Edition, FPS Unlock v1.9.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.9.0

- **Where the frame cap waits** (`FPSLimitPoint`): `early` (the default) waits at the start of the frame, before the game reads the controller, keyboard and mouse. `present` waits on the draw thread immediately before the gameplay Present and the loading-screen Present. Both use the same schedule. `MaxFPS` is still the rate.
- **SkipIntro** stays available when `FPSUnlock` is off, and defaults to on. An older INI with no `SkipIntro` key skips the logos.
- **Steep slides keep their footing** (`FixSlideContact`): the slide's ground flag is held for 1/30 s after the last real contact, so one short missed frame at the lip does not cancel the slide. At 30 FPS it still drops on the next frame.
- **Steering on a slide** (`FixSlideSteer`): a slide's turn restarts every frame, and Havok was throwing out that one-frame-old root motion, so the legs turned and the body barely moved. The threshold follows the frame time. At 30 FPS and below it is unchanged.
- **In-engine cutscene cameras** (`FixCutsceneCamera`): the characters already moved every frame; the camera held each 30 FPS key and then jumped. It is blended between those keys. A real cut still snaps. Pre-rendered movies are unchanged.
- **Soul counter** (`FixSoulCounter`): the on-screen count of a soul pickup follows the frame time instead of finishing several times too fast. A hitch adds at most four steps.
- **[Prepare to Co-op Edition](https://github.com/zofrea1/DS1-Prepare-to-Coop-PTDE) 1.3.0** is built on this release and includes it. If you have it, do not install this as well.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate. In-engine cutscene cameras are blended; a hard cut still snaps, and pre-rendered movies stay 30 FPS. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
