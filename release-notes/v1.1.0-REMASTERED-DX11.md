# Dark Souls: Remastered, FPS Unlock v1.1.0

High-FPS unlock with gameplay physics fixes. Files: `dinput8.dll` and `DSR-FPS-Unlock.ini`, next to `DarkSoulsRemastered.exe`. Works on the current Steam build only (SHA-1 `9150CC63C617332ED3C2C66E7566ED67E3292DA0`, 1.03.1).

## New in 1.1.0
- **Variable frame time.** The game now gets the measured frame time every frame. The frame cap is `MaxFPS` (was `TargetFPS`; the old name still works). Gameplay, physics, animation, menus and the mouse keep real-time speed when the frame rate dips below the cap.
- **Lock-on camera fix** (`FixCamera`). Switching targets and locking onto an enemy near the screen edge take the same time at any frame rate instead of snapping.
- **`CameraPtdeSpeed`** (off by default). Pans the lock-on camera at the original Dark Souls speed instead of the snappier Remastered speed.
- **Crash and start-up hardening.** Memory scans are guarded, hooks install once the window exists, the scheduler switch retries, and the log explains a failure to find the 60 Hz flipper.
- **Diagnostics.** A heartbeat every 30 seconds, a stall watchdog, flipper state logging, a minidump on crash.
- **New INI switches** `FixGraze`, `FixDamping`, `FixSlide`, joining `FixMoveDt`, `FixStepDown` and `FixCamera`. Every fix can be turned off to compare against retail.
- Default cap is 120 FPS. The INI is reorganised into `[Framerate]`, `[Physics]` and `[Diagnostics]`.

## Install
Copy both files next to the game exe. Set the display frequency to your monitor's rate and Vertical sync to off in the game's settings, then restart. Play offline and back up your saves.

## Known limits
See the README: lock-on body turn timing, the first walk-to-run hitch, a reported but unreproduced bonfire softlock at Firelink (`MenuInputFilter = false` is the test), and untested multiplayer. Send `DSR-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
