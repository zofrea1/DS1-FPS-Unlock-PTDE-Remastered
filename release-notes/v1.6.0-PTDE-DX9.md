# Dark Souls: Prepare to Die Edition, FPS Unlock v1.6.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.6.0

- **Controllers** (`FixController`): a current gamepad, or a second device such as a wheel or another pad, could leave the controller you are holding unread. The mod binds a connected gamepad, preferring the one being held. On by default.
- **Steam Deck:** the DLL forwards XInput to Wine's `xinput1_4`. Set the launch option `WINEDLLOVERRIDES="xinput1_3=n,b" %command%`.
- **Taller screens** (`FixAspect`): a 16:10 display, including the Deck's 1280x800, no longer keeps black bars above and below a 16:9 picture. The horizontal view stays the same and the extra height shows more of the world. A 16:9 display is unchanged. Leave DSfix `presentWidth` and `presentHeight` at 0. On by default.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; other multiplayer is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate; in-engine cutscenes can still look like 30 FPS. See the README. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
