# Dark Souls: Prepare to Die Edition, FPS Unlock v2.0.1

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 2.0.1

A cleaner build of 2.0.0. The fixes, settings and defaults are the same as in 2.0.0.

- **The development diagnostics are no longer in the DLL.** 2.0.0 carried its developer tools, switched off: recordings, hardware watchpoints, a render thread sampler and test hotkeys. Some virus scanners judged that code suspicious, and Nexus Mods held 2.0.0 for review. The published DLL is now built without them. It is smaller, and it no longer contains code that pauses threads or reads the keyboard.
- **The DLL has version information** (name, version, author, source link), shown under Properties > Details.
- The INI no longer has a `[Diagnostics]` section. If your old INI still has one, those keys are ignored.
- The effect timing fix (`FixSfxActions`) keeps its per-thread state without a static TLS section. It works the same in game.

**[Prepare to Co-op Edition](https://github.com/zofrea1/DS1-Prepare-to-Coop-PTDE) 1.6.0** includes the FPS Unlock 2.0.0 fixes. If you have it, do not install this as well.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Upgrading from 2.0.0: replace `xinput1_3.dll`; your INI keeps working. Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate. In-engine cutscene cameras are blended; a hard cut still snaps, and pre-rendered movies stay 30 FPS. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
