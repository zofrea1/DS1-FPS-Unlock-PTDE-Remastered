# Dark Souls: Remastered, FPS Unlock v2.0.1

High-FPS unlock with gameplay physics fixes. Files: `dinput8.dll` and `DSR-FPS-Unlock.ini`, next to `DarkSoulsRemastered.exe`. Steam build 1.03.1 only (SHA-1 `9150CC63C617332ED3C2C66E7566ED67E3292DA0`).

## New in 2.0.1

A cleaner build of 2.0.0. The fixes, settings and defaults are the same as in 2.0.0, including `StartOffline` and `SkipIntro`.

- **The development diagnostics are no longer in the DLL.** 2.0.0 carried its developer tools, switched off: a recording, hardware watchpoints and an input log. Some virus scanners judge such code suspicious, and Nexus Mods held the Prepare to Die Edition build of 2.0.0 for review. The published DLL is now built without them. It is smaller, and it no longer contains code that pauses threads or reads the keyboard.
- **The DLL has version information** (name, version, author, source link), shown under Properties > Details.
- The INI no longer has a `[Diagnostics]` section. If your old INI still has one, those keys are ignored.

Details for every fix are in the README.

## Install

Copy both files next to the game exe. Upgrading from 2.0.0: replace `dinput8.dll`; your INI keeps working. In the game's display settings set Frequency to your monitor's rate and Vertical sync off, then restart. Recommended: borderless fullscreen. Back up your saves. Well tested with Seamless Co-op; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban, and it starts the game offline by default (`StartOffline`). Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).
