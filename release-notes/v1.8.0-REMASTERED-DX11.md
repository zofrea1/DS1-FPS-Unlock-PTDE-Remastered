# Dark Souls: Remastered, FPS Unlock v1.8.0

High-FPS unlock with gameplay physics fixes. Files: `dinput8.dll` and `DSR-FPS-Unlock.ini`, next to `DarkSoulsRemastered.exe`. Steam build 1.03.1 only (SHA-1 `9150CC63C617332ED3C2C66E7566ED67E3292DA0`).

## New in 1.8.0

- **Original game movement** (`SlideFrictionPtde`, `GrazePtde`, `StepDownPtde`, `StepHeightPtde`, `AirDampingPtde`): Remastered's movement code is the original game's, but at 60 FPS it applies some per-frame values twice as often and changed two. Slide friction, the sprint slow-down against walls, the ground snap, the step height and airborne momentum now use the original game's values. On by default; set one to `false` for Remastered's own behaviour.
- **Original game HUD speed** (`HudPtdeSpeed`): an Estus heal fills the health bar, and the stamina bar's yellow part drains, at the original game's speed instead of twice as fast. On by default.
- **Stairs and slopes** (`FixFootIk`, `FootIkPtdeSpeed`): the hips followed each step of a staircase several times too fast at a high frame rate, so running up or down stairs and slopes bobbed. The foot placement now follows the frame time, at the original game's speed by default.
- **Stamina bar**: a sprint no longer leaves a yellow part on the stamina bar that grows, vanishes and comes back (`FixUI`).
- **Slides keep the ground** (`FixStepDown`): on fast slides, steering to the side could drop you off the slope, braking the slide and stopping its sound. Only the ground snap's own pull counts against its limit now, as in the game. The limit also holds at any frame rate (it could pull you down too fast above about 255 FPS).
- **`LockOnPtdeSpeed`** is on when the key is missing from an older INI, as the other original-speed switches are.

Details for every fix are in the README.

## Install

Copy both files next to the game exe. In the game's display settings set Frequency to your monitor's rate and Vertical sync off, then restart. Recommended: borderless fullscreen. Back up your saves. Well tested with Seamless Co-op; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).
