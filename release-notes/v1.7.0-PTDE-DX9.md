# Dark Souls: Prepare to Die Edition, FPS Unlock v1.7.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.7.0

- **Script memory** (`FixScriptMemory`): the enemy AI scripts clear out their used memory on a half-second timer, 15 frames at the native 30 FPS. At a high frame rate many times as much built up between clean-ups (twelve times at 360 FPS), which in Remastered made the game close itself in crowded areas. Clean-ups now come at least every 15 frames, as at 30 FPS. On by default, including when an older INI has no such key.
- **Taller screens** (`FixAspect`): the Steam Deck and other 16:10 screens now really see more. Until now the extra height was mostly the 16:9 picture stretched taller, because only part of the game's drawing took the wider view. The game's camera projection itself now gets the screen's shape, with the vertical view opened so the horizontal view stays the same (43 to 47.3 degrees on 16:10). The world, effects, lock-on marker and health bars all use it. The HUD, menus and movies are made for 16:9 and are still stretched a little.
- **Skip the start-up notice and logos** (`SkipIntro`, off by default): the autosave notice and the Bandai Namco, FromSoftware and Havok logos are not shown, and the title screen comes up straight away. Unlike DSfix's `skipIntro` it does not depend on the game's timing. Works with or without `FPSUnlock`.
- **Other players' characters** now walk, run and sprint as they really move at a high frame rate; a running player was shown walking.
- **Logs:** if a game script hits an error the game does not handle (the game then closes itself), the log has a `SCRIPT:` line saying which scripts failed and why. The heartbeat line shows how much memory the scripts use. Faults the mod catches itself are counted per place in the log instead of filling it, and the HUD fix no longer reads through stale pointers while the game rebuilds characters.
- **Prepare to Co-op Edition**, a separate co-op mod by the same author, includes this mod. If you have it, you have the FPS Unlock; do not install both.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; other multiplayer is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate; in-engine cutscenes can still look like 30 FPS. See the README. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
