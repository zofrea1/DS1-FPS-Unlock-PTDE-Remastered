# Dark Souls: Prepare to Die Edition, FPS Unlock v1.7.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.7.0

- **Script memory** (`FixScriptMemory`): the enemy AI scripts clean up their memory on a half-second timer, so at a high frame rate many times as much built up between clean-ups, and in a crowded area the game could run out and close itself. Clean-ups now come at least every 15 frames, as at 30 FPS. On by default, including with an older INI.
- **Taller screens** (`FixAspect`): on the Steam Deck and other 16:10 screens the extra height now really shows more of the world; before, most of it was the 16:9 picture stretched. The game's camera gets the screen's shape, with the same horizontal view (vertical 43 to 47.3 degrees on 16:10). The HUD, menus and movies are still stretched a little.
- **Skip the start-up notice and logos** (`SkipIntro`, off by default): the title screen comes up straight away. Unlike DSfix's `skipIntro`, it does not depend on the game's timing.
- **Other players** now walk, run and sprint as they really move; a running player was shown walking.
- **Logs:** a `SCRIPT:` line names a script error that makes the game close itself, the heartbeat shows the scripts' memory, and faults the mod catches are counted per place instead of filling the log.
- **[Prepare to Co-op Edition](https://github.com/zofrea1/DS1-Prepare-to-Coop-PTDE)**, a separate co-op mod, is built on this release and includes it. If you have it, do not install this as well.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate; in-engine cutscenes can still look like 30 FPS. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
