# Dark Souls: Prepare to Die Edition, FPS Unlock v1.4.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the optional DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.4.0
- **Brightness in windowed mode and with DXVK** (`WindowedGamma`, new): the game sets its brightness as a gamma ramp, which Direct3D only applies in exclusive fullscreen. Windowed, borderless, or with DXVK in a window, the picture came out darker with crushed blacks. The game's ramp is now applied in those modes too, so they look like fullscreen and the brightness setting works. Fullscreen is unchanged.
- **Ghosts and other players turn smoothly** (`FixGhosts`): at high frame rates bloodstain replays, wandering ghosts and other players' characters turned several times too far between updates and snapped back.

Details for every fix are in the README.

## Install
Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; other multiplayer is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits
Riding the edge of a short step can leave you stuck against it at a high frame rate; in-engine cutscenes can still look like 30 FPS. DXVK does not raise the frame rate on every PC (it helps most where the Windows Direct3D 9 driver is the bottleneck). See the README. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
