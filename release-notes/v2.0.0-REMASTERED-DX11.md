# Dark Souls: Remastered, FPS Unlock v2.0.0

High-FPS unlock with gameplay physics fixes. Files: `dinput8.dll` and `DSR-FPS-Unlock.ini`, next to `DarkSoulsRemastered.exe`. Steam build 1.03.1 only (SHA-1 `9150CC63C617332ED3C2C66E7566ED67E3292DA0`).

## New in 2.0.0

- **Starts offline** (`StartOffline`, on by default). After the title screen the game reads its launch setting (Network settings, Launch setting) to decide whether to log in. The mod sets it to Start Offline just before, so the game takes its own offline path and the modded game stays off the official servers, where players have reported temporary bans. It does nothing when Seamless Co-op is loaded, which has its own networking. To play online, set it to `false` and set Launch setting back to Start Online in the game. `DisableOnlineMode` also works as the key's name.
- **Skips the start-up logos** (`SkipIntro`, on by default). The logo screen is never opened, so the title screen comes up at once. The start-up step that opens it is replaced, not patched, so it works alongside Seamless Co-op. `IntroSkip` also works as the key's name.
- `StartOffline` and `SkipIntro` have their own switches and work whether or not `FPSUnlock` is on.
- **The undead dragons' acid slides as far and keeps its rhythm at any frame rate.** A sliding glob is landed again about three times a frame, and each landing's friction and ground factor counted per frame, so above 60 FPS the acid stopped short (`FixDamping`). A repeating projectile fires on the frame after its countdown runs out, so its volleys came faster at a high frame rate (`FixTimers`).
- **`BulletPtdeSpeed`** (default `true`) picks which rates those two fixes reproduce. Remastered applies the original game's per-frame values 60 times a second, so its acid loses its slide speed twice as fast and its acid stream fires twice as often as in the original game. `true` uses the original game's rates, `false` Remastered's own.
- Prepare to Die Edition also gets `FixSfxActions`, which brings back the acid on the ground above 30 FPS. Remastered's own effects were rebuilt without that problem.

Details for every fix are in the README.

## Install

Copy both files next to the game exe. In the game's display settings set Frequency to your monitor's rate and Vertical sync off, then restart. Recommended: borderless fullscreen. Back up your saves. Well tested with Seamless Co-op; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban, and it now starts the game offline by default (`StartOffline`). Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).
