# Dark Souls: Prepare to Die Edition, FPS Unlock v2.4.1

A patch release with preliminary support for RTX Remix: the new Dark Souls PTDE RTX mod runs alongside this mod, with this mod's frame rate and gameplay fixes. Files: `xinput1_3.dll`, `PTDE-FPS-Unlock.ini` and `dxvk_d3d9.dll`, next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Remastered is unchanged (v2.4.0).

Nothing changes for players who do not use RTX Remix.

## New: RTX Remix (preliminary)

- **`YieldToRtxRemix = auto`** (new, on by default). RTX Remix replaces the game's renderer with a path tracer and expects the game's own render passes. When it is installed beside the game (a `d3d9.dll` and `.trex\NvRemixBridge.exe`), this mod leaves the picture to it: its resolution, depth of field, effects, water, colour, shadow, filtering, aspect and HUD scale settings, DXVK, the Direct3D-level speed-ups, the effects fixes (`FixSfxSpawnRate`, `FixSfxActions`, `FixSfxDistortion`), `FixCutsceneCamera`, `HideMouseCursor`, `CacheInputReads` and `SkipIntro` are off, whatever the INI says, and the log says so. The frame rate, every gameplay fix, `FixController` and `FullscreenRefreshRate` stay this mod's. `true` applies the same anywhere, `false` never.
- **Your display's refresh rate under Remix.** Remix's bridge sets the fullscreen display mode itself, at 60 Hz. It now gets the rate `FullscreenRefreshRate` chooses (0, the default: the display's highest).
- **Setup with the Dark Souls PTDE RTX mod:** turn off its own frame rate unlock (`[FPSUnlock] Enabled=0` in its `rtx_comp\settings\remix-comp-proxy.ini`), so that only this mod drives the frame rate. DSfix is not compatible with the RTX mod.
- **Controllers:** launched through Steam with Steam Input on, the game found no controller under Remix (Steam Input and the Remix bridge both wrap DirectInput, which the game uses to find controllers). Start the game directly, or turn Steam Input off for it in Steam (Properties > Controller), and the controllers are found.
- Tested 2026-11-15 with an early build of the RTX mod: the picture as the RTX mod draws it, this mod's frame rate and fixes, the controller, and the display at its full refresh rate. Path tracing is usually the limit well before this mod's frame rate cap.

## Logs

- The log now says which XInput slot the game binds for a controller, when its controller poll first reads the pad and first sees a button, and whether the game's window was in front at its first input check (the game ignores all input while it is not), to make controller reports easier to follow.
- The focus lines read window titles without sending the window a message, so a busy window can no longer hold up the game while a title is logged.

**[Prepare to Co-op Edition](https://github.com/zofrea1/DS1-Prepare-to-Coop-PTDE) 2.0.1** includes FPS Unlock 2.4.1. If you have it, do not install this as well.

Details are in the README's [Prepare to Die Edition and RTX Remix](https://github.com/zofrea1/DS1-FPS-Unlock-PTDE-Remastered#prepare-to-die-edition-and-rtx-remix).

## Install

Copy the three files next to the game exe. Upgrading from 2.4.0: replace `xinput1_3.dll`; your INI keeps working (`YieldToRtxRemix` takes its default when the INI does not list it). Back up your saves. Steam Deck and Linux: launch option `WINEDLLOVERRIDES="xinput1_3=n,b" %command%`.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).
