# Dark Souls: Prepare to Die Edition, FPS Unlock v1.8.0

Unlocks the frame rate and fixes the physics, camera, timers and HUD that were written for exactly 30 FPS. Files: `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` (plus `dxvk_d3d9.dll` for the experimental DXVK), next to `DARKSOULS.exe`. Current Steam build only (`SizeOfImage` `0x11C2000`). Works with DSfix; set `unlockFPS 0` in `DSfix.ini`.

## New in 1.8.0

- **Stairs and slopes** (`FixFootIk`): the hips followed each step of a staircase several times too fast, so running up or down stairs and slopes bobbed. The foot placement now moves at the native speed at any frame rate.
- **Stamina bar**: a sprint no longer leaves a yellow part on the stamina bar that grows, vanishes and comes back (`FixUI`). Heals and other bar movements are unchanged.
- **Slides keep the ground** (`FixStepDown`): on fast slides, such as the slopes in the Depths and before the Bed of Chaos, steering to the side could drop you off the slope, braking the slide and stopping its sound. Only the ground snap's own pull counts against its limit now, as in the game.
- **Ground snap at any frame rate** (`FixStepDown`): above about 255 FPS the snap could pull you down faster than the game does; the limit now holds up to 1000 FPS.
- **[Prepare to Co-op Edition](https://github.com/zofrea1/DS1-Prepare-to-Coop-PTDE) 1.1.0** is built on this release and includes it. If you have it, do not install this as well.

Details for every fix are in the README.

## Install

Copy the files next to the game exe (`dxvk_d3d9.dll` only if you want to try DXVK). Recommended: exclusive fullscreen with `FullscreenRefreshRate = 0`. Back up your saves. Well tested with DSfix; official online play is untested.

**Online play: no guarantees.** The mod modifies the game in memory; using it on official servers could risk a ban. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).

## Known limits

Riding the edge of a short step can leave you stuck against it at a high frame rate; in-engine cutscenes can still look like 30 FPS. Send `PTDE-FPS-Unlock.log` and any `*-crash.dmp` with bug reports.
